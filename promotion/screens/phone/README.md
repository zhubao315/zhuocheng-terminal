# 真机截图说明（全离线版 2.1 信息屏）

落地页 `docs/screens/` 中的 7 张截图均为**红米 Note 2 真机实拍**，非电脑渲染、非模拟。

## 设备与环境

- 设备：Redmi Note 2（LineageOS 16 / Android 9，`hermes`）
- 连接：无线 adb `192.168.1.66:5555`
- 应用：拙诚日课 **v2.1.0 手动信息屏版**（`releases/zhuocheng-offline-2.0.apk`）
- 分辨率：1920 × 1080（横屏），原样保存
- 状态：断开电脑、断开网络；不加载 PhoneBox 外壳，无离线浮层、无顶部标题栏、无底部导航、无进度条

## 与旧版截图的区别

- v1.4.4 用 CSS 隐藏 PhoneBox 的「电脑未连接 / 点击唤醒」提示，但内容仍依赖电脑推送，纯离线时显示「等待推送…」。
- v2.0.0 把内容引擎搬进手机，但七页布局的顶部品牌栏和底部导航各占一条固定区域，信息被压缩。
- v2.0.1 改为全屏信息屏，但六类模块每 20 秒自动轮播，屏幕会自己跳走。
- **v2.1.0（当前）**：顶部中间改显「拙诚日课」品牌名、去掉进度条；默认静态停在「每日金句」，**不自动轮播**；底部一行六个栏目切换按钮，当前栏目高亮。

## 复现方式

```bash
adb connect 192.168.1.66:5555
adb -s 192.168.1.66:5555 install -r releases/zhuocheng-offline-2.0.apk
node promotion/screen_device_shots.mjs
```

脚本通过 WebView CDP 依次 `ZC.screenGo(0…5)` 手动切换六个栏目并截图，末尾校验「默认停在金句 → 等待 4.2 秒不自动跳 → `screenNext` 到伴读 → 回金句」，并恢复默认六栏目配置。配置面板截图同时验证六个栏目开关与保存按钮一屏可见、互不遮挡。

无头验证另见 `node promotion/screen_manual_qa.mjs`（默认金句、顶部品牌、无进度条、不自动轮播、手动切换、默认栏目配置，零异常）。
