# 真机截图说明（全离线版 2.0 信息屏）

落地页 `docs/screens/` 中的 7 张截图均为**红米 Note 2 真机实拍**，非电脑渲染、非模拟。

## 设备与环境

- 设备：Redmi Note 2（LineageOS 16 / Android 9，`hermes`）
- 连接：无线 adb `192.168.1.66:5555`
- 应用：拙诚日课终端 **v2.0.1 信息屏版**（`releases/zhuocheng-offline-2.0.apk`）
- 分辨率：1920 × 1080（横屏），原样保存
- 状态：断开电脑、断开网络；不加载 PhoneBox 外壳，无离线浮层、无顶部标题栏、无底部导航

## 为什么与旧版截图不同

v1.4.4 用 CSS 隐藏 PhoneBox 的「电脑未连接 / 点击唤醒」提示，但内容仍依赖电脑推送，纯离线时显示「等待推送…」。

v2.0.0 把内容引擎搬进手机，但七页布局的顶部品牌栏和底部导航各占一条固定区域，信息被压缩。v2.0.1 改为默认信息屏：屏幕全部交给内容，六类模块自动轮播，顶底只剩极简状态线与会淡出的提示。

## 复现方式

```bash
adb connect 192.168.1.66:5555
adb -s 192.168.1.66:5555 install -r releases/zhuocheng-offline-2.0.apk
node promotion/screen_device_shots.mjs
```

脚本通过 WebView CDP 切换轮播模块并截图，末尾校验自动轮播（两屏 / 5 秒，`0 → 1`）并恢复默认六模块配置。
