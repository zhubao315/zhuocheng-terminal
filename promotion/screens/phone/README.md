# 真机截图说明

落地页 `docs/screens/` 中的 5 张截图均为**红米 Note 2 真机实拍**，非电脑渲染。

## 设备与环境

- 设备：Redmi Note 2（LineageOS，`hermes`）
- 连接：无线 adb `192.168.1.66:5555`
- 应用：拙诚日课终端 v1.4.4（PhoneBox 0.9.29 基座 + 离线纯净补丁）
- 分辨率：1920 × 1080（横屏），截图后原样保存

## 离线纯净模式

原版 PhoneBox 外壳在电脑端不可达时会显示「电脑未连接 / 唤醒电脑 / 离线提示」浮层。
v1.4.4 通过 `scripts/hide_offline_panel.py` 在 `assets/www/style.css` 注入 CSS 隐藏这些元素：

- `#offline`、`#wake`：状态 pill 与唤醒按钮
- `.offline-msg`、`.deck-offline::after`：widget 内离线占位提示
- `.status .dot.off` + 文字替换：总览时钟卡状态行改为「离线就绪」

补丁只改 CSS，不改 JS，推送与所有 widget 功能保留；用原密钥 v1+v2 双签，指纹不变。

## 页面配置注入

真机应用数据被清除后没有页面配置，通过 WebView CDP 注入 `cfg_now.json`（新版六页配置）到
`localStorage.cfg`，重载后得到完整六页：总览 / 日课金句 / 日课打卡 / AI 伴读 / 静坐三省 / 定时中枢。
脚本：`inject_cfg.mjs`（用法见文件头部）。
