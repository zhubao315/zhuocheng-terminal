# 真机截图说明（全离线版 2.0）

落地页 `docs/screens/` 中的 7 张截图均为**红米 Note 2 真机实拍**，非电脑渲染、非模拟。

## 设备与环境

- 设备：Redmi Note 2（LineageOS 16 / Android 9，`hermes`）
- 连接：无线 adb `192.168.1.66:5555`
- 应用：拙诚日课终端 **v2.0.0 全离线版**（`releases/zhuocheng-offline-2.0.apk`）
- 分辨率：1920 × 1080（横屏），原样保存
- 状态：断开电脑、断开网络；应用内不加载 PhoneBox 外壳，没有离线浮层

## 为什么与 v1.4.4 截图不同

v1.4.4 只是用 CSS 隐藏 PhoneBox 外壳的「电脑未连接 / 点击唤醒」提示，金句与伴读仍依赖电脑端推送，纯离线时显示「等待推送…」。

v2.0.0 把内容引擎整体搬进手机：APK 的 WebView 入口被替换为 `docs/offline.html`，内置 999+999 语料与全部交互逻辑。截图因此是**真实离线内容**，不是空状态。

## 复现方式

```bash
adb connect 192.168.1.66:5555
adb -s 192.168.1.66:5555 install -r releases/zhuocheng-offline-2.0.apk
node promotion/offline_device_shots.mjs
```

脚本通过 WebView CDP 切换页面并截图；日课页的勾选是真实点击事件产生的状态。
