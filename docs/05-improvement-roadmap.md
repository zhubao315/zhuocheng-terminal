## 长期约束（每一版都要遵守）

1. Offline First / Zero API Key / Local First 不动摇。
2. 十二条日课原始名称与顺序永不擅改。
3. 每日记录只增不覆盖；语料重建可复现（固定种子）。
4. 未经真机验证的功能在 CHANGELOG 中标注「尚未验证」。
5. 修身不是 KPI：不用红色惩罚未完成、不因中断清空成就。
