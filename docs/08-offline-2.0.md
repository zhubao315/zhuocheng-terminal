# 全离线版 2.1 信息屏 · ZhuoCheng Terminal Offline

> 一句话：**把内容引擎从电脑搬进手机，再把手机变成一块安静、少互动的信息屏**。不配对、不联网、不启动电脑端；打开就全屏停在「每日金句」，顶部显示「拙诚日课」，六个栏目手动左右切换，不会自动跳走。

## 1. 为什么要做这一版

v1.4.4 只是把 PhoneBox 外壳的「电脑未连接 / 点击唤醒 / 等待推送」提示隐藏了，但金句和伴读仍由电脑上的 `daily_hub.py` 通过本地 API 推送。拔掉电脑后，墙上那块屏幕只能停在空状态——这不是「全离线」。

随后做出的七页交互版虽然把引擎搬进了手机，但红米 Note 2 横屏使用时，顶部品牌栏与底部七项导航各占去一条固定区域，内容被压缩、需要频繁点击才能看到不同信息。这与「床头信息屏」的定位相悖。

v2.0.1 把默认形态改为全屏信息屏，但采用**每 20 秒自动轮播六个模块**的方式：屏幕会自己跳走，正在看的一句金句或一页日课会被打断。v2.1 因此进一步改为**静态常亮 + 手动左右切换**：默认停在金句，想看哪一栏由用户决定，机器不替你翻页。

| 对比项 | 桥接版 v1.4.4 | 七页离线版 v2.0.0 | 轮播信息屏 v2.0.1 | 手动信息屏 v2.1（当前） |
|---|---|---|---|---|
| 内容轮换 | 电脑 Python 中枢推送 | 手机 WebView 本地定时器 | 手机本地自动轮播，每屏 20 秒 | **不自动轮播，默认停在金句** |
| 栏目切换 | 需操作电脑 / 推送 | 点底部七项导航 | 每 20 秒自动换屏 | **左右滑动 / 点左右半区 / 点栏目名 / 方向键** |
| 顶部标识 | PhoneBox 外壳 + 提示浮层 | 品牌标题栏 | 「纯离线 · 信息屏」+ 进度条 | **「拙诚日课」品牌名，无进度条** |
| 电脑端 | 必须常驻两个进程 | 完全不需要 | 完全不需要 | 完全不需要 |
| 网络 | 局域网 API | 不需要 | 不需要 | 不需要 |
| 界面形态 | 外壳 + 浮层 | 七页 + 顶部栏 + 底部导航 | 全屏信息屏 | **全屏信息屏 + 一行六栏目切换条** |
| 互动量 | 高 | 中 | 低（但会被自动打断） | **极低（想切才切，绝不被打断）** |
| 多端适配 | 无 | 固定布局 | 四种设备预设 + 留白 | 四种设备预设 + 留白 + 默认栏目 |
| 金句 / 伴读 | 推送到 widget | 999 + 999 条内嵌 | 999 + 999 条内嵌 | 999 + 999 条内嵌 |
| 打卡 / 档案 | 电脑无法回读 | 本机 localStorage | 共用同一份本地数据 | 共用同一份本地数据 |

## 2. 运行方式

- **APK**：`releases/zhuocheng-offline-2.0.apk`，安装后直接打开即进入信息屏，默认停在金句。
- **免安装**：手机浏览器打开 Pages 上的 [`offline.html`](offline.html)，功能一致。
- **桌面浏览器**：同样可用，便于按「桌面浏览器」预设调试；数据存在该浏览器本地。

## 3. 信息屏与互动

### 默认形态

顶部一行：左侧日期、中间**「拙诚日课」**品牌名、右侧时钟。中间是**静止**的大字内容；底部一行六个栏目切换按钮（金句 / 伴读 / 日课 / 习惯 / 静坐 / 档案），当前栏目高亮，下方是一行会自动淡出的操作提示；右下角一个半透明小齿轮（配置入口）。

**没有品牌标题栏、没有七项底部导航、没有进度条、没有自动轮播**，屏幕全部留给内容。刷新或重开应用都会回到默认栏目（金句），不会记住上次停留在哪一栏。

### 六个栏目

1. **每日金句**（默认）：全屏大字 + 出处 + 序号；横屏放大、竖屏与矮屏自动缩放，长句换行不截断。
2. **AI 伴读**：原文 + 出处 + 品读 + 今日一问，全部预生成。
3. **日课十二条**：四列（矮屏自适应）全览，勾选状态与今日进度可见。
4. **微习惯**：此刻一项行动 + 对应日课 + 真实时长 + 今日完成数。
5. **静坐三省**：呼吸圈 + 今日次数 + 回到自己的提示。
6. **成长档案**：连续天数、有记录天数、微习惯完成、静坐次/分与近 7 日日课条。

### 手动左右切换（完全不自动）

| 操作 | 触屏 | 鼠标 / 键盘（桌面） |
|---|---|---|
| 下一栏 | 向左滑 / 点屏幕右半区 / 点右侧栏目名 | 点右半区 / →、PageDown、空格 |
| 上一栏 | 向右滑 / 点屏幕左半区 / 点左侧栏目名 | 点左半区 / ←、PageUp |
| 直达某栏 | 点底部栏目条上的栏目名 | 点栏目名 |
| 打开多端配置 | 长按 0.65 秒 / 点右下角小齿轮 | 点小齿轮 / C |

信息屏下**栏目不自动切换、内容也不自动换新**（只有时钟在走），真正做到「停得住、不被打断」。金句 180 秒 / 伴读 600 秒 / 微习惯每小时的自动轮换，仍保留在「完整交互模式」里；勾选、收藏、导出等完整操作也都在该模式，两种模式共用同一份 `localStorage` 数据。

### 多端配置

长按或点右下角齿轮进入配置抽屉，可设置：

- **设备预设**：红米 Note 2 横屏 / 竖屏、平板大屏、桌面浏览器；默认「自动」按屏幕方向选横/竖屏预设。
- **固定区域留白**：顶部 / 底部各 0–240 像素，用于避开无法隐藏的系统栏或外壳区域。
- **显示**：字号倍率 0.8–1.8、**默认栏目**（默认「每日金句」）、夜间/日间主题、信息屏/完整交互模式。
- **显示栏目**：六个栏目可单独开关，勾选顺序即左右切换顺序；例如只留金句与日课，就只在这两栏之间切换。

配置只存本机；换设备时选对应预设，必要时微调留白。URL 也支持 `?profile=note2-portrait`、`?mode=full` 便于预览不同端。配置抽屉采用「头部/底部按钮固定 + 中间内容独立滚动」的布局，矮屏下六个栏目开关与保存按钮一屏可见、互不遮挡。

## 4. 技术实现

- 单文件应用：`docs/offline.html`（约 602 KB），内联数据、CSS、JS，无任何外链字体、图片、CDN。
- 源码：`web/offline/app.html` / `app.css` / `app.js`；由 `tools/build_offline_bundle.py` 从 `data/*.json` 构建。
- 信息屏：`body.screen-mode` 隐藏 `#topbar` / `#tabs` / `#main`，显示全屏 `#screen`；CSS 变量 `--safe-top` / `--safe-bottom` / `--screen-scale` 由配置驱动。
- 静态栏目：`screenOrder` 由 `screenModules` 依固定顺序生成，`screenAt` 每次启动按 `startModule` 复位到金句；`screenStep` / `screenGo` 只由手动事件触发，`screenTick` 仅更新时钟，`tick()` 在信息屏模式下不执行自动轮换。
- 切换条：`#scNav` 依 `screenOrder` 渲染六个短栏目名，当前项 `.active` 高亮，点击直达；事件用 `stopPropagation` 与左右半区点击逻辑隔离。
- 矮屏适配：`@media (max-height:700px) and (orientation:landscape)` 压缩日课网格、呼吸圈与配置抽屉；红米 Note 2 的 1080×608 CSS 视口下十二课完整可见。
- 数据：`localStorage['zhuocheng.offline.v2']`，按日期保存 `rike` / `habits` / `sits` / `notes`，另有收藏、主题、字号、多端配置与索引；历史日期只增不覆盖。旧版存档缺字段会在加载时补齐，默认栏目缺失时回落到金句。
- APK：`tools/build_offline_apk.py` 只替换 PhoneBox 基座的 `assets/www/index.html`，沿用原包名与图标；`scripts/sign_apk_v2.py` 做 v1+v2 双签，与旧版同一签名身份，可覆盖安装。

复现构建：

```bash
python tools/build_offline_bundle.py
python tools/build_offline_apk.py releases/zhuocheng-terminal-v2signed.apk releases/zhuocheng-offline-2.0-unsigned.apk
python scripts/sign_apk_v2.py releases/zhuocheng-offline-2.0-unsigned.apk releases/zhuocheng-offline-2.0.apk
python scripts/sign_apk_v2.py --verify releases/zhuocheng-offline-2.0.apk
```

冒烟测试：

- `node promotion/screen_manual_qa.mjs`：验证默认停在金句、顶部品牌名、无进度条、六栏目条、不自动轮播、手动 next/prev/go/点栏目名、配置面板默认栏目，零异常。
- `node promotion/screen_qa.mjs`：无头浏览器逐栏目布局回归与多端配置验证。
- `node promotion/screen_device_shots.mjs`：真机截图（需无线 adb 与 WebView 调试通道），含「默认金句 / 不自动轮播 / 手动切换」校验。

## 5. 真机验证（2026-11-25）

- 设备：红米 Note 2 / LineageOS 16 / Android 9 / 无线 adb `192.168.1.66:5555`。
- `adb install -r` 成功；打开后直接进入全屏信息屏：顶部日期 / 「拙诚日课」 / 时钟，中间大字金句，底部一行六栏目条（金句高亮），无顶底导航、无进度条、无「电脑未连接 / 点击唤醒 / 等待推送」。
- WebView CDP 逐栏目验证：金句、伴读、日课十二条、微习惯、静坐、档案均完整显示且无溢出；配置抽屉六个栏目开关与保存按钮一屏可见、互不遮挡。
- 手动切换验证：默认 `quote`，等待 4.2 秒仍为 `quote`（不自动轮播），`screenNext` → `companion`，`screenGo(0)` 回 `quote`，控制台零异常。
- 竖屏预设在 1080×1920 模拟视口下验证通过；横屏为真机原图。
- 七张真机截图见 `docs/screens/`（`01`–`06` 为信息屏六栏目，`07` 为多端配置）。

## 6. 已知边界

- 信息屏只做展示与栏目切换，勾选 / 收藏 / 导出需切到完整交互模式；两种模式数据互通。
- 信息屏默认不自动换内容，金句会一直保持同一条直到手动操作或切换模式；这是刻意设计，避免屏幕自己跳走。
- 全离线模式不采集硬件传感器数据（那是电脑端桥接版的能力）；界面只展示可靠的本地状态。
- 浏览器 `file://` 打开时，个别浏览器可能限制 localStorage；Pages 的 https 页面与 APK WebView 均已验证可用。
- 深层主题阅读、SQLite 迁移与年度总结仍按 `docs/05-improvement-roadmap.md` 的 V2.0 路线推进，不属于本次范围。
