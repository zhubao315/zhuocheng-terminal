# 全离线版 2.0 信息屏 · ZhuoCheng Terminal Offline

> 一句话：**把内容引擎从电脑搬进手机，再把手机变成一块少互动的信息屏**。不配对、不联网、不启动电脑端；打开就是全屏大字轮播，顶底不被固定栏占用。

## 1. 为什么要做这一版

v1.4.4 只是把 PhoneBox 外壳的「电脑未连接 / 点击唤醒 / 等待推送」提示隐藏了，但金句和伴读仍由电脑上的 `daily_hub.py` 通过本地 API 推送。拔掉电脑后，墙上那块屏幕只能停在空状态——这不是「全离线」。

随后做出的七页交互版虽然把引擎搬进了手机，但红米 Note 2 横屏使用时，顶部品牌栏与底部七项导航各占去一条固定区域，内容被压缩、需要频繁点击才能看到不同信息。这与「床头信息屏」的定位相悖。

v2.0.1 因此把默认形态改为**信息屏**：

| 对比项 | 桥接版 v1.4.4 | 七页离线版 v2.0.0 | 信息屏 v2.0.1（当前） |
|---|---|---|---|
| 内容轮换 | 电脑 Python 中枢推送 | 手机 WebView 本地定时器 | 手机本地自动轮播，每屏 20 秒可调 |
| 电脑端 | 必须常驻两个进程 | 完全不需要 | 完全不需要 |
| 网络 | 局域网 API | 不需要 | 不需要 |
| 界面形态 | PhoneBox 外壳 + 提示浮层 | 七页 + 顶部栏 + 底部导航 | **全屏信息屏，无顶底固定栏** |
| 互动量 | 高（推送+点击） | 中（切页/勾选） | **极低（默认零操作）** |
| 多端适配 | 无 | 固定布局 | **四种设备预设 + 固定区域留白** |
| 金句 / 伴读 | 推送到 widget | 999 + 999 条内嵌 | 999 + 999 条内嵌 |
| 打卡 / 档案 | 电脑无法回读 | 本机 localStorage | 与七页版共用同一份本地数据 |

## 2. 运行方式

- **APK**：`releases/zhuocheng-offline-2.0.apk`，安装后直接打开即进入信息屏。
- **免安装**：手机浏览器打开 Pages 上的 [`offline.html`](offline.html)，功能一致。
- **桌面浏览器**：同样可用，便于按「桌面浏览器」预设调试；数据存在该浏览器本地。

## 3. 信息屏与互动

### 默认形态

顶部只有一行日期 / 时间 / 「纯离线 · 信息屏」标识与一条细进度条；中间是按序轮播的信息；底部一行操作提示 6 秒后自动淡出；右下角有一个半透明小齿轮（配置入口）。**没有品牌标题栏，没有七项底部导航**，屏幕全部留给内容。

六类轮播模块：

1. **每日金句**：全屏大字 + 出处 + 序号；横屏放大、竖屏与矮屏自动缩放，长句换行不截断。
2. **AI 伴读**：原文 + 出处 + 品读 + 今日一问，全部预生成。
3. **日课十二条**：四列（矮屏自适应）全览，勾选状态与今日进度可见。
4. **微习惯**：此刻一项行动 + 对应日课 + 真实时长 + 今日完成数。
5. **静坐三省**：呼吸圈 + 今日次数 + 回到自己的提示。
6. **成长档案**：连续天数、有记录天数、微习惯完成、静坐次/分与近 7 日日课条。

### 极少互动

| 操作 | 触屏 | 鼠标 / 键盘（桌面） |
|---|---|---|
| 换下一屏 | 轻触一下 / 向左滑 | 单击 / →、PageDown |
| 换上一屏 | 向右滑 | ←、PageUp |
| 暂停 / 继续轮播 | 双击 | 双击 / 空格、Enter |
| 打开多端配置 | 长按 0.65 秒 / 点右下角小齿轮 | 点小齿轮 / C |

不操作时模块按设定秒数自动换屏；暂停状态只影响当前会话，刷新后恢复自动轮播。完整勾选、收藏、导出等操作保留在「完整交互模式」里（配置中切换），与信息屏共用同一份 `localStorage` 数据。

### 多端配置

长按进入配置抽屉，可设置：

- **设备预设**：红米 Note 2 横屏 / 竖屏、平板大屏、桌面浏览器；默认「自动」按屏幕方向选横/竖屏预设。
- **固定区域留白**：顶部 / 底部各 0–240 像素，用于避开无法隐藏的系统栏或外壳区域。
- **显示**：字号倍率 0.8–1.8、每屏秒数 5–300、夜间/日间主题、信息屏/完整交互模式。
- **轮播模块**：六类内容可单独开关，例如只留金句与日课。

配置只存本机；换设备时选对应预设，必要时微调留白。URL 也支持 `?profile=note2-portrait`、`?mode=full` 便于预览不同端。

## 4. 技术实现

- 单文件应用：`docs/offline.html`（约 597 KB），内联数据、CSS、JS，无任何外链字体、图片、CDN。
- 源码：`web/offline/app.html` / `app.css` / `app.js`；由 `tools/build_offline_bundle.py` 从 `data/*.json` 构建。
- 信息屏：`body.screen-mode` 隐藏 `#topbar` / `#tabs` / `#main`，显示全屏 `#screen`；CSS 变量 `--safe-top` / `--safe-bottom` / `--screen-scale` 由配置驱动。
- 矮屏适配：`@media (max-height:700px) and (orientation:landscape)` 压缩日课网格、呼吸圈与配置抽屉，并把「保存并应用」按钮固定在抽屉底部；红米 Note 2 的 1080×608 CSS 视口下十二课完整可见。
- 数据：`localStorage['zhuocheng.offline.v2']`，按日期保存 `rike` / `habits` / `sits` / `notes`，另有收藏、主题、字号、多端配置与索引；历史日期只增不覆盖。旧版存档缺字段会在加载时补齐并默认进入信息屏。
- APK：`tools/build_offline_apk.py` 只替换 PhoneBox 基座的 `assets/www/index.html`，沿用原包名与图标；`scripts/sign_apk_v2.py` 做 v1+v2 双签，与旧版同一签名身份，可覆盖安装。

复现构建：

```bash
python tools/build_offline_bundle.py
python tools/build_offline_apk.py releases/zhuocheng-terminal-v2signed.apk releases/zhuocheng-offline-2.0-unsigned.apk
python scripts/sign_apk_v2.py releases/zhuocheng-offline-2.0-unsigned.apk releases/zhuocheng-offline-2.0.apk
python scripts/sign_apk_v2.py --verify releases/zhuocheng-offline-2.0.apk
```

冒烟测试：`node promotion/screen_qa.mjs`（无头浏览器逐模块截图 + 配置验证，零异常）；真机截图：`node promotion/screen_device_shots.mjs`（需无线 adb 与 WebView 调试通道，含自动轮播校验）。

## 5. 真机验证（2026-11-25）

- 设备：红米 Note 2 / LineageOS 16 / Android 9 / 无线 adb `192.168.1.66:5555`。
- `adb install -r` 成功；打开后直接进入全屏信息屏：日期时间 + 进度条 + 大字金句 + 一行淡出提示，无顶底导航、无「电脑未连接 / 点击唤醒 / 等待推送」。
- WebView CDP 逐模块验证：金句、伴读、日课十二条、微习惯、静坐、档案均完整显示且无溢出；配置抽屉保存后留白与字号即时生效；两屏 / 5 秒配置下自动轮播 `0 → 1` 验证通过；控制台零异常。
- 竖屏预设在 1080×1920 模拟视口下验证通过；横屏为 1920×1080 真机原图。
- 七张真机截图见 `docs/screens/`（`01`–`06` 为信息屏六模块，`07` 为多端配置）。

## 6. 已知边界

- 信息屏只做展示，勾选 / 收藏 / 导出需切到完整交互模式；两种模式数据互通。
- 全离线模式不采集硬件传感器数据（那是电脑端桥接版的能力）；界面只展示可靠的本地状态。
- 浏览器 `file://` 打开时，个别浏览器可能限制 localStorage；Pages 的 https 页面与 APK WebView 均已验证可用。
- 深层主题阅读、SQLite 迁移与年度总结仍按 `docs/05-improvement-roadmap.md` 的 V2.0 路线推进，不属于本次范围。
